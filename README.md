# Bike Buyers Analysis

## Project Overview

This project analyzes customer demographic and socioeconomic data to identify patterns associated with bicycle purchases.

The analysis was completed using Microsoft Excel. The project involved data cleaning, exploratory analysis, PivotTables, calculated fields, and an interactive dashboard.

## Business Questions

* What percentage of customers purchased a bike?
* What types of customers are more likely to purchase a bike?
* Which customer characteristics show higher or lower bike purchase rates?
* What marketing opportunities can be identified from these patterns?

## Dataset

The dataset contains customer information including:

* Gender
* Age
* Income
* Education
* Occupation
* Region
* Marital Status
* Commute Distance
* Bike Purchase Status

## Data Cleaning

The dataset was reviewed and prepared for analysis by:

* Checking for duplicate records
* Checking for missing values
* Reviewing categorical values for consistency
* Creating age-group categories
* Preparing the dataset for PivotTable analysis

## Analysis

The analysis examined bike purchase behavior across different customer characteristics, including age, gender, income, education, occupation, region, and commute distance.

### Key Findings

* **48.05%** of customers purchased a bike.
* The **Middle Age** group represented the largest age category in the dataset.
* Customers in **Europe and the Pacific region** showed higher purchase rates than customers in North America.
* **Professional** occupations had the highest bike purchase rate among the occupation groups analyzed.
* Bike purchase rates varied across education groups.
* Customers with shorter commute distances represented important segments for further analysis.
